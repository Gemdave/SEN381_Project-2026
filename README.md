## Project Overview
CivicConnect is a community-focused service request management platform designed to replace fragmented, unmonitored communication channels (email, phone calls, WhatsApp, spreadsheets) with a single, traceable, and audited digital environment. The platform enables community requesters to submit and track issues, operational staff to manage and resolve requests through controlled lifecycle transitions, and management to maintain complete visibility over service-level performance.

This repository serves as the single source of engineering truth for the product, capturing progressive evidence across requirements baseline, architectural decisions, quality assurance, security engineering, and operational deployment

## Core System Capabilities

* **Requester Portal:** Submit service requests with categorisation, view real-time request status and historical logs, and receive automated lifecycle updates.
* **Staff Operations Panel:** Search, filter, and sort authorized requests, assign ownership, record actions/comments, and transition request statuses through controlled workflows.
* **Management & Oversight Dashboard:** Monitor open and overdue activity, analyze service metrics across custom dimensions, and audit lifecycle accountability.
